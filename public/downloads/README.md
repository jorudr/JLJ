# Installer files

Download URLs are configured in src/shared/downloads.js.
Place the following installers in this directory before building the site:

- JLJ-Windows.exe
- JLJ-macOS.dmg

These filenames are placeholders until real builds are supplied. No installer
files are currently included. Download buttons deliberately remain enabled.
Alternatively, replace the URLs in src/shared/downloads.js with release URLs.

Free and Full use the same installer for each OS. They are access plans,
not separate application builds.
